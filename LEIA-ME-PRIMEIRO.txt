=== INSTRUÇÕES PARA CONTINUAR O PROJETO ===

1. Abra esta pasta no VS Code.
2. Abra o terminal (Ctrl + `).
3. Ative o ambiente: source venv/bin/activate
4. Ligue o servidor: python manage.py runserver 0.0.0.0:8000
5. Abra no navegador: http://localhost:8000/
6. Para o servidor: Ctrl + C
7. Parar caso fechei errado: fuser -k 8000/tcp
